# Reserve Muse-On while Enabled

While Codex Muse-On is Enabled and Connected, its per-device raw-button filtering remains applied even when Codex is not foreground, so raw digits, arrows, and function keys cannot leak into another Mac app. Shortcut dispatch is still allowed only when Active. Disable, normal Quit, disconnect, permission failure, or a Safety latch attempts verified Pass-through restoration; if restoration cannot be verified, the app remains latched with a specific error and sends no synthetic actions rather than claiming that pass-through succeeded. The exceptional `Quit Anyway` path preserves that dispatch block through termination, requests termination only from the app-owned listener task when present, and leaves the next launch conservative until Retry and Neutral Entry succeed.
