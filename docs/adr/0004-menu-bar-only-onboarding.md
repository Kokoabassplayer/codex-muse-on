# Use menu-bar-only onboarding

Codex Muse-On runs without a normal Dock icon or main window. A new installation appears as a Disabled menu-bar item, and the user chooses **Enable Codex Muse-On…** to see one concise setup alert before permission requests and Start Automatically are enabled. This favors a low-friction RunCat-style utility over a conventional onboarding window while preserving explicit one-time consent.
